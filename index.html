                    AI Enablement Kit — Preview
                    
      
    
                    
    
                    
      
                    
        
                    Prompt Engineering Playbook
                    
        
                    5 before/after prompts for common engineering tasks (test case generation, status summaries, design review), each with the structure that made it better: role, format, explicit constraints — plus a script that estimates the token/response savings.
                    
      
                    
      
                    
        
                    Building Your First Agent
                    
        
                    Session 3 of the 4-part program: pairs build a minimal classify → retrieve → escalate prototype for one of their own tasks, using the same pattern as the Support Agent case study, and demo it in 5 minutes.
                    
      
                    
      
                    
        
                    AI Usage Guidelines
                    
        
                    What stays human-led, what data should never go into a prompt, and when to escalate instead of trust a confident-sounding answer — the non-negotiables from the Support Agent's design carried into a written policy.
                    
      
                    
      
                    
        
                    Workshop Structure
                    
        
                    4 sessions × 1.5 hours: Fundamentals & use-case spotting → Prompt engineering & token optimization → Build your first agent → Measurement, governance and documentation. Every session ends with a participant-made deliverable, not just slides.
                    
      
                    
      
                    
        
                    Adoption Measurement
                    
        
                    A re-audit at 4 weeks using the same audit checklist, plus a lightweight internal-doc template (Confluence/SharePoint-ready) so every new tool ships with an owner, a "what NOT to use this for," and a measured before/after.

                    What this demonstrates
                    
    
                    
      
                    Reading a process before recommending anything.
                    The Console's Audit stage — and the Workflow Audit Framework case study built the same way.
                    
      
                    Prioritizing with judgment, not hype.
                    The Prioritize stage never invents ROI or hours saved without baseline data.
                    
      
                    Choosing the right intervention — including none.
                    The Design stage's verdict system, and the Support Agent's escalate-instead-of-guess default.
                    
      
                    Handing off something a team can run without me.
                    The Implementation Brief, its Confluence/Jira export formats, and the Enablement Kit.
