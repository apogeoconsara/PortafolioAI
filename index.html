                      How it works
                      
    
                      One goal picker routes your input to the right combination of specialized steps — the same shared roster of agents, recombined differently for each objective.
                      
    
                      
      
                      Auditor
                      Understands the process before recommending anything.
                      
      
                      Prioritizer
                      Scores impact vs. effort — no invented ROI.
                      
      
                      Solution Designer
                      Picks the right intervention, including no automation at all.
                      
      
                      Prompt Engineer
                      Rewrites a prompt with explicit technique, not guesswork.
                      
      
                      Documentation / Enablement
                      Turns a decision into something a team can run without me.
